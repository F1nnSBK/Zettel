# Map of Content: Post-Bachelor Master & Direct PhD Target-Grid

## Strategic Profile & Application Baseline

* **Origin Degree:** B.Sc. Computer Science / Informatik (DHBW Ravensburg) – **210 ECTS**
* **Core Criteria:**
  1. **Finanzierung:** 0 € Studiengebühren ODER voll bezahltes Gehalt / Direct PhD Stipendium.
  2. **ECTS-Kompatibilität:** Direct-Entry / Master-Zulassung mit 210 ECTS (keine Nachforderungs-Schikanen).
  3. **No-Fluff Rule:** Fokus auf funktionierende Systeme, High-Performance Computing, Dateninfrastruktur, Vektor-Engines und MLOps. Null Toleranz für reine Beweis-Bürokratie oder weichen Entrepreneurship-Sprech.
  4. **Unternehmertum / Side-Business:** UG kann im Hintergrund weiterlaufen (insb. bei DACH-Stellen / Skandinavien).
